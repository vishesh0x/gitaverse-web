# Contributing

Corrections and improvements are welcome.

1. Install Node 22 or newer, then run `npm install` and `npm run dev`.
2. Keep the site static and free of third-party requests: no analytics, trackers or externally hosted fonts or scripts.
3. Check pages at phone width (320px) and in both light and dark themes before opening a pull request.
4. Run `npm run build` and make sure it finishes without errors.

The chapter, glossary and topic data in `src/data` is copied from the app's `assets/content` folder. Fix content mistakes in the app repository first, then copy the file here.
